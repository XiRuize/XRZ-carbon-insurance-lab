# 碳保险定价面板与智能体问答系统

围绕两款碳保险产品（CEA 现货采购保险、长期碳价跃升保险）的定价研究、可视化面板与智能体问答系统。

## 仓库结构

```
├── panel/                        # 可视化面板（单文件 Web 应用，浏览器直接打开）
│   └── index.html
├── CEA现货保险完整方案_20261009/  # 产品一：CEA 现货采购保险完整方案
│   ├── 完整方案.md               # 方案全文（定价、条款、压力测试、实施顺序）
│   ├── 阅读与复算说明.md         # 复算指引
│   ├── 统一计算结果.json         # 定价计算结果
│   ├── 公式索引.json / manifest.json
│   ├── data/                     # 181 条 CEA 日度行情（2026-01-05 → 09-30）
│   └── *.py                      # 数据处理与定价计算脚本
└── 长期碳排放权价格跃升保险/      # 产品二：长期碳价跃升保险
    ├── 01_引擎/                  # 定价引擎（DDF、保费、准备金、压力测试等 30+ 模块）
    ├── 02_产物/                  # 报价 JSON、承保表、验收断言、原始文献
    └── 03_交付物/                # 复核报告、设计决策存根、论文全文
```

## 面板功能

- **五大栏目**：实时碳价 / 总览 / 产品一 CEA 现货采购保险 / 产品二 长期碳价跃升保险 / 智能体
- **动态可视化**：总览页四幅波浪式渐变动画速览图（181 条真实行情、10 万条蒙特卡洛路径、4 档保费、42 项压力断言）；产品页内置可交互蒙特卡洛计算实验室（区块自助重采样）
- **实时定价**：智能体一键获取全国碳市场最新价（官方接口 + 云端同步），浏览器端 10,000 条路径真实重算短期 / 长期保费
- **决策问答**：接入云端大模型，回答"哪天买、买多少、怎么买、组合成本最少"，给出短期 / 长期 / 期货（预留）组合配置方案

## 使用说明

- 面板：直接用浏览器打开 `panel/index.html`；智能体问答需部署到已配置的服务环境（Origin 校验）
- 方案复算：按 `CEA现货保险完整方案_20261009/阅读与复算说明.md` 执行
