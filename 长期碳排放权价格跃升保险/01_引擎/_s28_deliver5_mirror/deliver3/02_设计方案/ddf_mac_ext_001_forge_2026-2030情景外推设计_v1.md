### 0.1 版本号冲突：D7「验证契约 v4 → v5」与既有工作版契约的号位重叠

**事实**：
- 既有工作版契约文件名为 `validation_contract_ddf_mac_ext_001.json`（**无版本后缀**），其内部字段 `version: "v5"`、`contract_id: "ddf_mac_ext_001_forge_v5"`（Forge v5 勘误轮产物，19415 B）。

- 派单 D7 要求「验证契约 **v4 → v5** 变更清单」，deliverable 4 要求「validation_contract **v5** JSON」。

**冲突点**：若按 D7 字面理解，似乎应以「v4 契约」为基线升 v5；但现存工作版契约**已自称 v5**，且不存在 `_v4.json` 以外的 v4 契约文件——即 v4→v5 的升版在既有链上**似已完成或已发生口径漂移**（此漂移 Critic A8 已部分记录）。

**登记处置（不静默）**：
1. 本方案**不改名、不修改、不覆盖**任何既有契约文件；新建契约文件名定为 `validation_contract_ddf_mac_ext_001_v5.json`（**该文件名在既有目录中不存在**，无覆盖）。
2. 新契约 `contract_id` 定为 **`ddf_mac_ext_001_forge_scenario_v5`**，以 `scenario` 限定词与既有 `ddf_mac_ext_001_forge_v5`（2023–2025 设计契约）**对象区隔**——二者同号（v5）但**对象不同**：既有 v5 = 2023–2025 外推链契约；本 v5 = 2026–2030 情景外推契约。
3. 在契约内新增 `version_lineage_registration` 字段，逐字记录本冲突与既有 v5 的 sha 提示；并在 D7 变更清单中以「按对象区隔读法」列示，**不主张既有 v5 现应改称 v4**。

### 0.2 参数标签内部张力：Route M 的 P2 中档「~3.4%（折算待下游）」

**事实**：Route M §2 表 P2 中档标「~3.4%（折算待下游）」；而 15 五碳强度硬锚「累计 −17%」的**精确年化**为 `(1−0.17)^(1/5)−1 = −3.657%`。

**登记处置**：本方案在 D3 中**以硬锚精确年化 −3.657% 为「锚口径」**，并将「−3.4%」列为**待核低载标签**；二者差异（1.12 pp 累积）在 D3 一致性问题中显式登记，**不静默以任一值覆盖另一值**。

### 2.2 映射链要点与口径代用披露

1. **P2 直接锚定 C 路径**：由 `g_C,t=(1+g_Y,t)(1+g_s,t)−1` 生成 C 的逐年增速。此法与 2023–2025 回望段的 **P3b「强度法」同构**，故 2026–2030 C 输入可视为 P3b 的**前向延续**；**P1 路径（`C=ρE`）在前望段的对应物** = 以 P3 的 g_E 与 2022 逐省 `ρ` 桥接生成 C（同回望段双路径结构）。两路径差异仍归**轴2 口径带**，禁入轴1（P-4）。
2. **全国代分省的适用范围**：P1（g_Y）与 P7（g_L）在前望段**无分省逐年来源**（Route M U1/U2 明载），故全国代分省；此为**与 2023–2025 对 L 处理同构的既有口径代用**，非新增缺陷，但**外推年数由 3 增至 8，代用累积误差放大**，须在 D6 与论文披露（登记于契约 `D2_substitution`）。
3. **P4 不直接入链**：用电量非 DDF 五变量之一，仅作 E 侧交叉校验（电力约占终端能源，其增速应不显著背离 E 增速）；不一致时**登记背离**，不改数值。
4. **P8 不入链**：碳价仅作情景背景；reference_carbon_price=25.1364 元/吨（政策倍数分母）沿用不变。
5. **P6→K 的三重口径代用**（承接 T-10 §10）：(i) 全国代省级；(ii) 固定资产投资(不含农户)代固定资本形成总额；(iii) 名义代实际。**如实披露，不构造偏离带**。

## 三、D3 自洽性约束（本设计核心）

### 3.1 硬锚年的年化（锚口径）

**锚 A（碳强度累计 −17%）**：
```
(D3-1)   Π_{t=2026}^{2030} (1+g_s,t) = 1 − 0.17 = 0.83
         等强度年化： g_s* = 0.83^(1/5) − 1 = −0.03657030 = −3.6570%/yr
         2026 单年官方目标 −3.8% 与 −3.657% 同向（前高后缓），一致。
```
**锚 B（非化石占比 25%）**：
```
(D3-2)   p_2025 = 0.217,  p_2030 = 0.25  ⟹ (1−p): 0.783 → 0.750
         等速份额路径： g_{(1−p)}* = (0.750/0.783)^(1/5) − 1 = −0.0085746 = −0.8575%/yr
```

### 3.2 联立自洽方程（核心）

以「能源 × 化石份额 × 化石碳因子 ≈ 排放」的分解 `C_t = (1−p_t)·E_t·κ_t`（κ=单位化石能源排放，基准情景取 `g_κ=0`，即化石能源碳因子不变；燃料结构漂移作为敏感性维度）：

```
(D3-3)   (1+g_s,t) = (1+g_C,t)/(1+g_Y,t)
                    = [ (1+g_{(1−p)},t)·(1+g_E,t)·(1+g_κ,t) ] / (1+g_Y,t)

(D3-4)   把锚 A、锚 B 代入（g_κ=0），解出「双锚联立隐含的能源增速」：
                    g_E*(g_Y) = (1+g_s*)·(1+g_Y)/(1+g_{(1−p)}) − 1
                    = 0.9717642·(1+g_Y) − 1
```
等价反向式（给定能源增速，解隐含 GDP）：
```
(D3-5)   g_Y*(g_E) = (1+g_{(1−p)})·(1+g_E)/(1+g_s*) − 1 = 1.0290566·(1+g_E) − 1
```

**联立解（锚口径）**：

| P1 档 | g_Y | **双锚隐含 g_E\*** | 落入 P3 档位 |
|:--|--:|--:|:--|
| 低 | 4.0% | **+1.0635%** | P3 低–中之间 |
| 中 | 4.5% | **+1.5494%** | **P3 中档（1.5–2%）正中** |
| 高 | 5.0% | **+2.0352%** | P3 中档上缘 |

反向读法：

| P3 档（代表值） | **双锚隐含 g_Y\*** | 与 P1 档位关系 |
|:--|--:|:--|
| 低（≈0%） | **+2.906%** | **低于 P1 下限 4.0%** → 不自洽 |
| 中（1.55%） | **+4.50%** | = P1 中档 → **自洽** |
| 高（>4.0%，取 4.0%） | **+7.02%** | **远超 P1 上限 5.0%** → 不自洽 |

### 3.3 一致性残差与偏离登记

定义**残差**：
```
(D3-6)   r_E(scenario) = g_E^{scenario} − g_E*(g_Y^{scenario})
         判据： |r_E| ≤ 0.5 pp/yr  → 记为「一致」；否则「不自洽」，须登记偏离量
```
逐情景判定：

| 情景 | P1 | P3 | g_E\*(双锚) | 残差 r_E | 判定 | 偏离量（登记） |
|:--|--:|--:|--:|--:|:--|:--|
| **S-中（推荐主报告）** | 4.5% | 1.55% | +1.5494% | ≈0 | ✅ **自洽** | 无 |

### 4.2 压力测试层（路径乙）的 K 口径——推荐与理由

**问**：压力测试层用哪一口径？

**推荐：取「路径乙三档」（g_K = 0.0442 / 0.1281 / 0.2067），承接 D-005 裁定；承载 `R_widen_max_cross`。**

**理由（逐条）**：
1. **D-005 已裁定**：压力测试层 = 路径乙三档，承载 `R_widen_max_cross = 1.829924796431446`（2025, max_c）；单 high 档降为诊断条目 **D-B1**（不删除）。
2. **单 high 档不构成「上界」**：D-B1 的 `R_widen_max_cross = 0.8957471841436361`，**低于**同期口径对照层（层甲）的 `1.441220809959782`——**比对照层更窄的层不能充当「压力测试上界」**，与用户 D-004 赋予该层的定位相矛盾。
3. **三档是「包络」**：层乙三档覆盖 low–high 全幅，其 `I_t`/`U_t` 端点最宽，方为使该层成为**上界**的口径。

**备选方案（Alternative）与权衡**：

| 方案 | 内容 | 优点 | 代价 | 处置 |
|:--|:---|:---|:---|:---|
| **推荐（主）** | 层乙 = 路径乙三档 | 真上界；承接 D-005；与 T-09/甲/丙**同源可逐位复核** | high 档 0.2067 经 Route J 6 条反证判为**非现实**；8 年复合（×4.5）使层乙带过宽，须特判为「包络上界」 | 采 |
| **备选（诊断并列）** | 层乙 = 单 high 档（D-B1） | 更贴「最坏单值」直觉 | **不构成上界**（窄于层甲）；与 D-004 定位矛盾 | 仅作诊断条目 D-B1 并列，**不入压力层** |
