## §2 R_widen 的形式化与尺度不变性证明（T1）

> **先定式、后算值**（硬约束）。本节先给出定义与性质证明，回测数值推迟至 §2.4。

### 2.1 定义式 ←R-01 ←R-03

设 `c ∈ W*` 为识别窗口取样点，`t` 为报告年，`U_t(c)` 为该点该年的**二维并集带**（轴1 识别区间 ∪ 轴2 口径带，契约 `P-4` 要求二者分列后取并集），`t0 = 2022` 为基准年：

```
半宽_t(c)      = ( U_t(c).hi − U_t(c).lo ) / 2
半宽_ref(c)    = 半宽_{t0}(c)        # t0 = 2022，同口径
R_widen(t, c)  = 半宽_t(c) / 半宽_ref(c)
```

> **定义式本身零改动**（本轮禁止改动）。以下仅澄清 `半宽_ref` 的**两个自洽口径及其适用域**（R-01）与退化断言的**条件**（R-03）。

- **基准取法（口径自洽，硬约束）**：`半宽_ref` **必须**在同一次外推路径、同一读法（归一化基准 / K 档设定 / C 路径设定 / E 增速设定）下，于 **t=2022** 处取半宽。**禁止**跨口径混用 → 契约 `P-12`。

- **两个 ref 口径须明示区分（R-01(a)）**：`半宽_ref` 有且仅有两个自洽口径，分属两类场景，**不可互换、不可跨场景搬用**：
  - **口径甲 — 真外推（基准 1995–2022，`t0 = 报告年 = 2022`）**：K 三档 / C 双路径 / E 全国增速在 `t0 = 2022` 处**均不需外推** → **轴2 退化** → `U_2022 = I_2022`（该退化的适用域见下 R-03）→ `半宽_ref = 半宽(2022 识别区间) = (555.8009 − 168.2073)/2 = **193.7968** 元/吨`（deliver2 精确求根锚点 A-4）。→ **`193.7968` 唯一绑定「真外推」场景**。
  - **口径乙 — 回测（子测试 A/B/C 基准分别为 1995–2019 / 1995–2020 / 1995–2021）**：2022 是 **holdout 年**，`holdout 年 ≠ 基准年`，三轴已张宽 → `U_2022 ≠ I_2022` → `半宽_ref` 取**该子测试自身 2022 的半宽**（A = 196.1 / B = 179.2 / C = 187.9 元/吨）。→ **各子测试就地取值**。

- **回测禁硬编码（R-01(b)；`P-12` 兜底）**：**回测中禁止**把 `193.7968` 硬编码为 ref；**必须就地取该子测试 2022 的半宽**（A=196.1 / B=179.2 / C=187.9）。此禁在 §2.1 前文即可读处**明确写出**，以免 Tester 误读 §2.1 而套用真外推口径；契约 `P-12` 已在契约侧兜底。

- **退化断言的适用域（R-03，条件句）**：上句「2022 处 K 三档与 C 路径均退化重合、`U_2022 = I_2022`」**仅在「基准年 = 报告年 `t0 = 2022`」的真外推下成立**；**回测中 `holdout 年 ≠ 基准年`（如 A 子测试 2022 处 `U = [−131.3, 260.8] ≠ I = [−131.3, 216.6]`，上端差 **44.2**），三轴已张宽，此退化不适用**。

- **同源性提示（R-01(c)）**：真外推的 ref（`193.7968`，**纯识别区间**半宽）与回测的 ref（各自**就地值** 196.1 / 179.2 / 187.9）**不同源**。因此：**回测的 `R_widen` 数值不可直接搬用**到真外推；回测对 `R_widen` 的验证是**比值结构同构**层面的验证——即「外推 1–3 年把带撑大多少倍」这一**相对量可迁移**，而其**绝对分母（ref）不可迁移**。

- **报告口径**：主报告在交付锚点 `c0`（b₁=−1）给 `R_widen(t, c0)`；另报 W* 网格上的 `max_c R_widen(t, ·)`。
- **通过条件**：`R_widen(t, c) ≤ 1.5`（阈值由用户预设，见 §3）。

### 2.2 性质一：尺度不变（证明）

设对同一读法下的 MAC 水平施加**公共乘法缩放** `MAC → λ·MAC`（λ>0）——这正是 deliver2 所证「标度不可识别」对应的变换类（MAC 水平仅在尺度意义下被识别）。则区间端点 `U.hi, U.lo → λU.hi, λU.lo`（端点随水平同比缩放），于是 `半宽 → λ·半宽`。代入：

```
R_widen' = (λ·半宽_t) / (λ·半宽_ref) = 半宽_t / 半宽_ref = R_widen
```

**故 R_widen 对 MAC 水平的公共乘法缩放严格不变**（λ 约去，逐位恒等）。这不依赖任何弹性、不含任何绝对水平量，是纯粹的两个同口径半宽之比。∎

### 2.3 性质二：不含 naive_err 项（证明与对照）

- **不含 err（结构证明）**：定义式 2.1 中一切量均为**半宽**（区间宽度），`naive_t`、`truth_t`、`naive_err_t` **均不出现在式中**。故 `R_widen` 对朴素基准的表现**无任何依赖**。
- **无反向激励（推论）**：令朴素点退化（`naive_t` 任意偏离 `truth_t`，`naive_err_t → ∞`），`R_widen` 恒等不变。即**不存在「基准更差 → 判据更优」的路径**。
- **对照证明（err 放大 2 倍变换）**：对 T-08 全部 6 点的 `naive_err_t` 一律乘 2（`naive_err → 2·naive_err`）：

| 判据 | 变换前 | 变换后 | 是否翻转 |
|:---|:---|:---|:---|
| `R_half = median(半宽/naive_err)` | **3.899（不通过）** | **1.950（通过）** | **是，判据翻转** |
| `R_widen = 半宽_t/半宽_ref` | 1.162（max） | **1.162（max，恒等）** | **否，不变** |

`R_half` 因分母含 err 而被该变换整体减半、跨过阈值；`R_widen` 因 err 不入式而**恒等不变**。这直接暴露：`R_half` 把「基准点预测的失误幅度」误当作方法优劣的尺度，导致其正相关于基准的退化；`R_widen` 只度量「外推相对基准年的加宽」，不受此污染。∎

### 2.5 两条判据各自度量什么，以及为何 R_half 不可作门槛

| 判据 | 度量对象 | 数学形态 | 为何不能/能作门槛 |
|:---|:---|:---|:---|
| `R_half` | 「**区间相对某一次朴素基准点的效率**」 | 半宽 / 基准点误差 | **不可**作门槛：分母 `naive_err` 是**基准点自身的失误幅度**，非方法属性；它与半宽独立变化（CV 0.4569 vs 0.0579，相差 7.89 倍），使 `R_half` 近似 `常数/err`。故它**奖励基准更差、惩罚外推更准**（范畴错误）；且隐含要求 err≥66.40（失误率 26.6%），与实际保真要求背离。 |
| `R_widen` | 「**外推引入的额外口径不确定性**」——外推年带宽相对同口径基准年带宽的放大倍数 | 两个**同口径半宽之比** | **可**作门槛：只含「带有多宽」这一方法属性，尺度不变（§2.2）、不含 err（§2.3），无反向激励；其阈值对「外推把带撑大到什么程度」直接可解释（§3）。 |

> **结论**：`R_half` 记录为**机制诊断量**（保留失败，§4）；外推门槛依据改用 `R_widen`。

## §3 阈值 1.5 的事前合理性论证（T2）

> 防「事后放宽」质疑：**阈值由用户在判据设计前预设**，Forge 未参与选值，**非**为使结果通过而事后选定。本节仅**论证其事前合理性**。

### 3.1 论证基础：deliver2 基准半宽 193.7968 元/吨

识别区间半宽 `193.7968 = (555.8009 − 168.2073)/2`（deliver2 精确求根，锚点 A-4），并集 f-区间 `[168.2073, 555.8009]`。**该半宽在 deliver2 中已是「尺度不确定性本身」的结构性度量**，非本轮新造：2022 省际均值 MAC 仅 190.53 元/吨，而识别半宽 193.80 元/吨——即标度不确定性在**基准年**已达「与水平同量级」（≈100% 相对）。因此：

- `半宽_ref` 是**不可再压**的结构性下界（尺度不可识别性的直接后果），不是可调的设计参数。
- 外推 t 年时，K/E/C 三轴口径不确定性只可能**加宽**、不可能收窄（外推 = 增加口径自由度）。
- （**适用域**：本节的 193.7968 为**真外推口径**的 ref；回测口径的 ref 各自就地取值，见 §2.1；证明 1.5 的事前合理性只依赖真外推口径 ←R-01。）

### 3.2 3 年视野下的量级推演（定量）←R-02

`R_widen ≤ 1.5` 等价于**外推引入的额外半宽** `Δ = 半宽_t − 半宽_ref ≤ 0.5 × 193.7968 = 96.90 元/吨`。以 2022–2025 仅 **3 年链接**为约束，逐轴估算其相对跨度：

| 轴 | 3 年口径跨度（可算的输入量，非弹性乘推） | 量级 |
|:---|:---|:---|
| **K 三档** | k_high/k_low 三年复合 `((1.2067)/(1.0442))^3 = 1.15562^3 = **1.5433**` | 单轴输入跨度 **54.3%** |
| **E 全国增速** | T-03 实测 3 年累积偏离 **7.7%**；经 P1（C=ρE）由 η_b 中位 0.847 传导 → MAC 相对影响 ≈ `0.847 × 0.077 = **6.5%**` | 单轴 ≤7% |
| **C 双路径** | P1/P3 二者均锚定 `C_raw(2022)`，仅经 ρ 漂移分化 | 设计带宽 ≤ K 轴，量级小 |

**叠加为何 1.5 宽严适中（三点定量支撑）**：

1. **上界与单轴输入跨度同阶**：最大的单轴输入跨度是 K 三档 **1.5433**。若外推带「照搬」K 输入全跨度，`R_widen` 上限约 1.54——**略高于 1.5**。取阈值 1.5 即：**容忍接近整个 K 档输入跨度**（外推带宽不超过资本口径输入的跨度本身），但**阻断**「比输入跨度还大的失控加宽」。这是「宽」的一面。（**诚实保留**：此即「阶段 B 真外推存在判据失败的可能」之出处，处置语义见 §3.4 与契约 `G2-C3.on_block` ←R-04。）
2. **三轴部分抵消，实测远低于上界**：K 档上行（g_K↑）经 η_k<0 **压低** MAC，E 增速上行经 η_b>0 **抬高** MAC——**异号抵消**；再叠加 30 省**精确代入 + 算术平均**（裁定 A，禁止弹性乘推，因 f_t 是对数量平均的倒数关系），实测加宽远小于线性上界。T-08 回测在**同 3 年视野、同三轴**下、**3 个实质检验点**测得 `R_widen ∈ [1.032, 1.162]`（**平凡点 1.000 不计**，见 §2.4 ←R-02），最大值 1.162。取 1.5 相对实测最坏值留 **29.1% 裕度**（`1.5/1.1618 − 1 = 29.1%`）——这是「严」的一面。
3. **「基准分量 ≥2/3」原则（阈值的直接解释）**：`R_widen = 1.5` 时总半宽 `= 1.5 × 193.7968 = 290.70 元/吨`，其中**基准（尺度不确定性）分量占比 `193.7968 / 290.70 = 66.68% ≥ 2/3`**。即 1.5 恰好是「报告的带宽仍由**可信的尺度不确定性**主导（≥2/3）」的临界点；超过 1.5 则带宽的主导来源变为外推口径漂移，区间退化为「外推不确定性报表」而非「识别区间」。该解释**先于结果存在**，与任何实测值无关。

**结论**：1.5 落在「实测最坏 1.162（下）」与「单轴输入跨度 1.543（上）」之间，且对应「基准分量 ≥2/3」这一独立原则。它既**不轻易否决**一次真实的 3 年外推（容忍接近全 K 档跨度），又**不放行**超出输入跨度本身的失控加宽。故 1.5 为事前合理、宽严适中的门槛。

### 3.3 与旧阈值的对照（说明旧判据为何被弃）

- 旧 `R_half ≤ 3.0` 隐含要求每点 `naive_err ≥ 半宽/3 = 66.40 元/吨`（失误率约 26.6%）——把「方法越准反而越难过闸」写进了判据（err 越小 R 越大）。
- 新 `R_widen ≤ 1.5` 只要求「外推不把带撑大到 1.5 倍以上」，与基准点失误幅度**解耦**。

### 3.4 阻塞语义：`G2-C3.on_block`（R-04，新增，非缺陷）←R-04

§3.2 第 1 点已**诚实承认**「若照搬 K 输入全跨度，`R_widen` 上限约 1.54 > 1.5」，即**阶段 B 真外推存在判据失败的可能**。契约 `G2-C3` 此前只写「`R_widen > 1.5 → G2_block`」，**未写明阻塞之后怎么办**。本轮在契约 `G2-C3` 增 `on_block` 字段，并在本设计文档同步其语义（**判据条件本身零改动**：仍是 `R_widen > 1.5 → G2_block`）：

- `R_widen > 1.5` → **G2 阻塞，不自动放行**（不因判据③自身、也不因判据②的既有失败而放行）。
- **亦不自动放弃**：**不得**因一次 `R_widen > 1.5` 而径直转《不可行性报告》或终止设计。
- **须保留已算出的全部数值并如实披露**（不省略、不淡化、不裁剪任何档/点）。
- 将**处置权提请用户裁决**；可选项包括（不限于）：**接受更宽带报告** / **调整阈值** / **终止**。
- **阈值本身由用户预设**；**Forge 与 Tester 均无权调整**（`P-8`「据回测结果反向调整阈值」亦为 contract_fail）。

> **同步位置**：契约 `G2-C3.on_block`（结构化字段）；设计 §3.2 第 1 点（诚实保留）与本节；CSV `criterion` 组 `R_widen_max` 行 note；对齐表 §四 R_widen 行。

### 5(a) §5.1/§5.4「回测期输入 = 真值」与外推现实矛盾 —— 更正
