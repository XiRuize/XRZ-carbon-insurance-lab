# 阅读与复算说明

研究日期为2026年10月9日，数据冻结至2026年9月30日。

## 阅读顺序

1. 阅读Word主文档，包含28页、38个原生可编辑公式、32张表格和181条实际使用的2026年日行情。
2. 查看`统一计算结果.json`，核对合同参数、单阶段及主保单报价、企业方案和报价状态。
3. 查看`data`中的行情、历史赔款回放、候选方案及情景CSV。行情来源和质量标记保留在`CEA输入日行情.csv`。
4. 需要重新计算时，使用`prepare_cea_complete_plan_20261009.py`。需要重新生成Word时，再使用`build_cea_complete_plan_20261009.py`。

## 计算口径

- 本版共用种子2026100903生成的100,000条60交易日路径，用于价格预测、保险定价及企业方案。
- 20日历史回放保留此前每个起点20,000条路径、种子20261009加起点索引的结果，它是已经使用过的历史回放。
- 主文档20日1,000吨报价为1,055.25元。此前约1,050.84元属于另一随机路径版本，两者不能理解为新的市场报价变动。
- 赔付公式为`eta * quantity * clip(index - budget - deductible, 0, cap_band)`。
- 企业数值、费用、资金成本、保费预算及容量均标为研究假设，尚无真实企业商业额度。

## 复算依赖和覆盖行为

数值计算需要Python与NumPy；Word生成还需要python-docx。全部核心程序及辅助模块已包含在包中。复算程序会覆盖`data`中的计算结果及`统一计算结果.json`。输入行情和随机种子相同时结果可复现，已在本交付目录运行验证，核心结果文件SHA256一致。

原始历史回放记录随包保留；如更换数据，需要重新生成回放并设计新的独立验证，不能仅重跑当前报价脚本后认定模型通过验证。

规则边界、数量关系和文件复算已检查；模型赔款低估尚待校准，策略尚待独立验证。正式报价和交易建议状态均为false。企业资料、官方最新行情、保险人容量、实际费用和执行条件经核验后，应重新计算。
